# Agent 对话功能如何使用

项目的功能非常的多，这里先介绍最为常用的 Agent 对话功能的使用流程，其他功能后续会陆续介绍

### 9. 点进 Agent 智能体对话界面
智能体提供了三种对话模式，分别是当前文档问答、自动知识问答、开放式提问

#### 9.1 当前文档问答 模式
用户需要先选择某个文档后，进行对话，这样是可以最为精确的检索和智能联想整个文档中的内容
<img alt="9.1 当前文档问答 模式：12 1" src="/img/super-agent/项目使用讲解/12-1.png" width="100%" />

#### 9.2 自动知识问答 模式
用户无需选择文档，系统会自动根据用户的提问进行相关文档的检索和联想，来回答用户的问题。

如果在之前的上传文档中，填写了知识路由相关的信息，那么在此模式中，系统会优先根据用户的问题匹配相关的知识路由来进行文档的检索和联想，这样可以更高效的找到相关的内容来回答用户的问题。
<img alt="9.2 自动知识问答 模式：12 2" src="/img/super-agent/项目使用讲解/12-2.png" width="100%" />

#### 9.3 开放式提问 模式
有时用户并不想检索内部资料，而是需要联网搜索一些外部的信息来回答用户的问题，这时就可以使用开放式提问模式，系统会自动调用外部的搜索引擎来获取相关的信息来回答用户的问题。
<img alt="9.3 开放式提问 模式：12 3" src="/img/super-agent/项目使用讲解/12-3.png" width="100%" />
