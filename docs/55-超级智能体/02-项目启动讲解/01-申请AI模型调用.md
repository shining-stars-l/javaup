# 申请AI模型调用

:::info 注意
本章节是将所有的AI模型调用的申请流程都放在了一起，等到了后续章节需要进行调用的时候，根据需要的模型来选择对应的申请流程即可，
:::

:::danger API Key 安全警告
API Key 是你的身份凭证，等同于密码，一旦泄露他人可消耗你的额度：
- 不要提交到 Git 仓库
- 不要发到群聊、论坛
- 不要写在前端代码里
- 生产环境用环境变量或密钥管理服务
:::

## 申请 Tavily
