# 框架实战快速上手

前面三篇我们聊了Agent的概念、架构和协作模式，都偏理论。这篇开始动手，用**Spring AI Alibaba**框架从零搭建一个Agent应用。

Spring AI Alibaba在1.1版本中提供了生产级的**ReactAgent**实现，它基于Graph（图）的运行时来驱动Agent的推理和工具调用。听起来复杂，用起来其实挺简单的。

## 5分钟搭建你的第一个Agent

先不管原理，咱们用最少的代码跑起来一个Agent。

### 引入依赖

```xml
<dependency>
    <groupId>com.alibaba.cloud.ai</groupId>
    <artifactId>spring-ai-alibaba-agent-framework</artifactId>
    <version>1.1.0.0</version>
</dependency>
<dependency>
    <groupId>com.alibaba.cloud.ai</groupId>
    <artifactId>spring-ai-alibaba-starter-dashscope</artifactId>
    <version>1.1.0.0</version>
</dependency>
```

### 配置模型

```yaml
spring:
  ai:
    dashscope:
      api-key: ${DASHSCOPE_API_KEY}
```

### 最简Agent

```java
@RestController
@RequestMapping("/agent")
public class SimpleAgentController {
    
    @Autowired
    private ChatModel chatModel;
    
    @GetMapping("/hello")
    public String hello(String question) {
        // 三行代码创建一个Agent
        ReactAgent agent = ReactAgent.builder()
                .name("simple_agent")
                .model(chatModel)
                .build();
        
        return agent.call(question).getText();
    }
}
```

访问 `http://localhost:8080/agent/hello?question=你好` ，Agent就能回答你了。

当然，这个Agent啥工具都没有，只能聊天。接下来我们给它加上各种能力。

## 核心组件一览

ReactAgent由多个组件构成，每个组件负责不同的能力：

| 组件 | 作用 | 必需？ |
|------|------|--------|
| Model | 大脑，负责推理和决策 | 是 |
| Tools | 手脚，执行具体动作 | 否 |
| System Prompt | 行为规范，定义角色和约束 | 否 |
| Memory | 记忆，保持对话上下文 | 否 |
| Hooks | 生命周期钩子，在关键节点插入逻辑 | 否 |
| Interceptors | 拦截器，修改请求和响应 | 否 |

下面我们逐一拆解。

## 给Agent配个好大脑：Model

Model是Agent的核心，所有的推理、决策都依赖它。

### 基础配置

```java
// 方式一：注入Spring管理的ChatModel（推荐）
@Autowired
private ChatModel chatModel;

ReactAgent agent = ReactAgent.builder()
        .name("my_agent")
        .model(chatModel)
        .build();
```

```java
// 方式二：手动创建ChatModel
DashScopeApi dashScopeApi = DashScopeApi.builder()
        .apiKey("sk-xxxxxxxxxxxx")
        .build();

ChatModel chatModel = DashScopeChatModel.builder()
        .dashScopeApi(dashScopeApi)
        .defaultOptions(DashScopeChatOptions.builder()
                .withModel("qwen-plus")
                .withTemperature(0.7)
                .withMaxToken(2000)
                .build())
        .build();
```

### 参数调优建议

| 参数 | 说明 | Agent场景建议 |
|------|------|--------------|
| temperature | 随机性，0~1 | 0.3~0.7，太高容易跑偏 |
| maxToken | 最大输出长度 | 根据任务复杂度设置，2000起步 |
| topP | 核采样参数 | 0.9左右 |
| model | 模型选择 | qwen-plus或qwen-max |

## 让Agent动起来：Tools工具箱

没有工具的Agent只能聊天，有了工具才能真正"做事"。

### 定义工具的三种方式

**方式一：函数式定义（简单场景）**

```java
ToolCallback orderQueryTool = FunctionToolCallback.builder(
        "query_order",  // 工具名
        (orderId, toolContext) -> {
            // 模拟查询订单
            return "订单 " + orderId + " 状态：已发货，预计明天送达";
        }
)
.description("根据订单号查询订单状态")
.inputType(String.class)
.build();

ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .tools(orderQueryTool)
        .build();
```

**方式二：注解式定义（推荐）**

```java
public class OrderTools {
    
    @Tool(description = "根据订单号查询订单详情")
    public OrderInfo queryOrder(
            @ToolParam(description = "订单号") String orderId) {
        // 实际业务逻辑
        return orderService.getById(orderId);
    }
    
    @Tool(description = "申请退款")
    public String applyRefund(
            @ToolParam(description = "订单号") String orderId,
            @ToolParam(description = "退款原因") String reason) {
        return refundService.apply(orderId, reason);
    }
}

// 使用
ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .tools(ToolCallbacks.from(new OrderTools()))
        .build();
```

**方式三：实现BiFunction接口（需要上下文）**

```java
public class OrderQueryTool implements BiFunction<String, ToolContext, String> {
    
    @Override
    public String apply(String orderId, ToolContext toolContext) {
        // 可以从ToolContext获取更多信息
        OverAllState state = (OverAllState) toolContext.getContext().get("_AGENT_STATE_");
        RunnableConfig config = (RunnableConfig) toolContext.getContext().get("_AGENT_CONFIG_");
        
        // 业务逻辑
        return "订单状态：已发货";
    }
}

ToolCallback tool = FunctionToolCallback.builder("query_order", new OrderQueryTool())
        .description("查询订单")
        .inputType(String.class)
        .build();
```

### ToolContext能拿到什么

ToolContext是工具执行时的数据中心，可以获取：

```java
// Agent的全局状态
OverAllState state = (OverAllState) toolContext.getContext().get("_AGENT_STATE_");

// 运行配置
RunnableConfig config = (RunnableConfig) toolContext.getContext().get("_AGENT_CONFIG_");

// 历史消息
List<Message> messages = (List<Message>) state.value("messages").orElse(List.of());
```

### 工具设计最佳实践

1. **名字要直白**：`query_order`比`qo`好，LLM更容易理解
2. **描述要清晰**：告诉LLM这个工具干什么、什么时候用
3. **参数要有说明**：每个参数都加上`@ToolParam`描述
4. **返回值要有用**：返回LLM能理解和使用的信息

## Agent的行为规范：System Prompt

System Prompt定义了Agent的"人设"和行为规范。

### 两种设置方式

```java
// 方式一：简单字符串
ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .systemPrompt("你是一个订单查询助手，帮助用户查询订单状态。")
        .build();

// 方式二：复杂指令（推荐）
String instruction = """
    你是电商平台的智能客服助手，具备以下能力：
    
    1. 查询订单状态和物流信息
    2. 处理退换货申请
    3. 解答商品相关问题
    
    工作原则：
    - 回答要简洁明了
    - 涉及敏感操作（如退款）要确认用户意图
    - 遇到无法处理的问题，建议用户联系人工客服
    
    回复风格：
    - 使用礼貌用语
    - 适当使用emoji增加亲和力
    """;

ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .instruction(instruction)
        .build();
```

### Prompt设计要点

1. **明确角色**：告诉Agent它是谁
2. **列出能力**：让Agent知道它能做什么
3. **设定边界**：明确什么不能做
4. **规范风格**：定义回复的语气和格式

## 让Agent有记忆：Memory组件

没有记忆的Agent，每次对话都是"失忆"状态。加上Memory，Agent才能记住之前聊了什么。

### 短期记忆（会话内）

```java
ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .saver(new MemorySaver())  // 基于内存的记忆
        .build();

// 使用时需要指定threadId来区分不同会话
RunnableConfig config = RunnableConfig.builder()
        .threadId("user_12345")
        .build();

agent.call("我想查一下订单", config);
agent.call("就是昨天买的那个", config);  // Agent能记住上文
```

### 长期记忆（持久化）

Spring AI Alibaba内置了多种持久化Saver：

```java
// MySQL持久化
MysqlSaver mysqlSaver = new MysqlSaver.Builder()
        .dataSource(dataSource)
        .build();

// PostgreSQL持久化
PostgresSaver postgresSaver = new PostgresSaver.Builder()
        .dataSource(dataSource)
        .build();

// 文件系统持久化
FileSystemSaver fileSaver = new FileSystemSaver.Builder()
        .directory("/path/to/memory")
        .build();

ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .saver(mysqlSaver)
        .build();
```

使用MySQL持久化后，框架会自动创建`graph_checkpoint`和`graph_thread`两张表来存储对话状态。应用重启后，Agent依然能"记得"之前的对话。

## 执行流程的控制点：Hooks与Interceptors

这两个组件让你能在Agent执行过程中"插一脚"。

### Hooks：生命周期钩子

Hooks在Agent执行的关键节点触发：

```java
@HookPositions({HookPosition.BEFORE_AGENT, HookPosition.AFTER_AGENT})
public class LoggingHook extends AgentHook {
    
    @Override
    public String getName() {
        return "logging_hook";
    }
    
    @Override
    public CompletableFuture<Map<String, Object>> beforeAgent(
            OverAllState state, RunnableConfig config) {
        System.out.println("Agent开始执行，用户输入：" + getLastUserMessage(state));
        return CompletableFuture.completedFuture(Map.of());
    }
    
    @Override
    public CompletableFuture<Map<String, Object>> afterAgent(
            OverAllState state, RunnableConfig config) {
        System.out.println("Agent执行完成");
        return CompletableFuture.completedFuture(Map.of());
    }
}

// 使用
ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .hooks(List.of(new LoggingHook()))
        .build();
```

**Hook执行位置**：
- `BEFORE_AGENT` / `AFTER_AGENT`：Agent整体执行前后
- `BEFORE_MODEL` / `AFTER_MODEL`：每次模型调用前后

### Interceptors：请求/响应拦截

Interceptors可以修改模型的输入和输出：

```java
public class SensitiveWordInterceptor extends ModelInterceptor {
    
    @Override
    public ModelResponse interceptModel(ModelRequest request, ModelCallHandler handler) {
        // 前置检查：敏感词过滤
        if (containsSensitiveWords(request.getMessages())) {
            return ModelResponse.of(
                    AssistantMessage.builder()
                            .content("检测到不当内容，已拦截。")
                            .build()
            );
        }
        
        // 正常调用模型
        ModelResponse response = handler.call(request);
        
        // 后置处理：可以修改响应
        return response;
    }
    
    @Override
    public String getName() {
        return "sensitive_word_interceptor";
    }
}

// 使用
ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .interceptors(new SensitiveWordInterceptor())
        .build();
```

### Hooks vs Interceptors

| 维度 | Hooks | Interceptors |
|------|-------|--------------|
| 作用层级 | Agent生命周期 | 单次模型调用 |
| 能否修改数据 | 一般不修改 | 可以修改请求/响应 |
| 典型用途 | 日志、监控、审计 | 过滤、增强、降级 |

## 结构化输出

有时候你希望Agent返回特定格式的数据，而不是自由文本：

```java
// 定义输出结构
public record OrderInfo(
    String orderId,
    String status,
    String expectedDelivery
) {}

ReactAgent agent = ReactAgent.builder()
        .name("order_agent")
        .model(chatModel)
        .outputType(OrderInfo.class)  // 指定输出类型
        .build();

String response = agent.call("查询订单ORD123456的状态").getText();
// 返回JSON格式：{"orderId":"ORD123456","status":"已发货","expectedDelivery":"明天"}
```

**注意**：如果要返回列表，需要包装一层：

```java
public record OrderListResult(List<OrderInfo> orders) {}
```

## 流式输出

对于长回复，流式输出能提升用户体验：

```java
@GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<String> stream(String question, String sessionId) {
    ReactAgent agent = ReactAgent.builder()
            .name("order_agent")
            .model(chatModel)
            .saver(new MemorySaver())
            .build();
    
    RunnableConfig config = RunnableConfig.builder()
            .threadId(sessionId)
            .build();
    
    return agent.stream(question, config)
            .map(output -> {
                if (output instanceof StreamingOutput) {
                    Message msg = ((StreamingOutput<?>) output).message();
                    return msg != null ? msg.getText() : "";
                } else {
                    return "";  // 节点完成的通知
                }
            })
            .filter(text -> !text.isEmpty());
}
```

## 实战：搭建订单查询助手

综合以上组件，我们来完整实现一个订单查询助手：

```java
@Service
public class OrderAssistant {
    
    @Autowired
    private ChatModel chatModel;
    
    @Autowired
    private DataSource dataSource;
    
    public ReactAgent buildAgent() {
        // 定义工具
        ToolCallback[] tools = ToolCallbacks.from(new OrderTools());
        
        // 系统提示词
        String instruction = """
            你是订单查询助手，可以帮用户：
            1. 查询订单状态和物流信息
            2. 查询商品详情
            3. 申请退款（需确认用户意图）
            
            回复要求：
            - 简洁明了，重点突出
            - 涉及金额操作要再次确认
            """;
        
        // 持久化记忆
        MysqlSaver saver = new MysqlSaver.Builder()
                .dataSource(dataSource)
                .build();
        
        return ReactAgent.builder()
                .name("order_assistant")
                .model(chatModel)
                .tools(tools)
                .instruction(instruction)
                .saver(saver)
                .hooks(List.of(new LoggingHook()))
                .build();
    }
    
    public String chat(String message, String userId) {
        ReactAgent agent = buildAgent();
        RunnableConfig config = RunnableConfig.builder()
                .threadId("session_" + userId)
                .build();
        return agent.call(message, config).getText();
    }
}

// 工具类
public class OrderTools {
    
    @Tool(description = "查询订单状态，包括物流信息")
    public String queryOrderStatus(
            @ToolParam(description = "订单号") String orderId) {
        // 模拟查询
        return "订单 " + orderId + " 状态：已发货，顺丰快递SF123456，预计明天送达";
    }
    
    @Tool(description = "查询商品详情")
    public String queryProduct(
            @ToolParam(description = "商品ID或名称") String productQuery) {
        return "商品信息：蓝牙耳机 Pro，价格299元，库存充足";
    }
    
    @Tool(description = "申请退款，会发起退款流程")
    public String applyRefund(
            @ToolParam(description = "订单号") String orderId,
            @ToolParam(description = "退款原因") String reason) {
        return "退款申请已提交，订单号：" + orderId + "，原因：" + reason + "，预计3个工作日处理";
    }
}
```

## 小结

这篇我们动手实践了Spring AI Alibaba的ReactAgent：

**核心组件**：
- **Model**：大脑，负责推理决策
- **Tools**：手脚，执行具体动作
- **System Prompt**：行为规范
- **Memory**：对话记忆
- **Hooks**：生命周期钩子
- **Interceptors**：请求响应拦截

**工具定义三种方式**：
- 函数式（FunctionToolCallback）
- 注解式（@Tool）
- 接口式（BiFunction）

**记忆持久化**：
- MemorySaver（内存）
- MysqlSaver/PostgresSaver（数据库）
- FileSystemSaver（文件）
