# 知识路由（三层漏斗）

当系统里有多个知识库（多个文档）时，用户问了一个问题，该去哪个文档里找答案？这就是知识路由要解决的问题。

它的思路是"逐层缩小范围"：先确定大的知识域（Scope），再确定具体话题（Topic），最后锁定目标文档（Document）。像漏斗一样，一层一层过滤。

## 三层结构

```
Scope（知识域）
  └── Topic（话题）
        └── Document（文档）
```

举个例子：
- Scope：Java 后端开发
- Topic：Spring Boot 配置
- Document：《Spring Boot 自动配置原理》

## 核心接口

### KnowledgeRouteService

**包路径：** `org.javaup.ai.manage.service`

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `route(question, rewriteQuestion)` | `KnowledgeRouteDecision` | 路由主入口，返回决策结果 |
| `recordShadowRoute(conversationId, exchangeId, selectedDocumentId, question, rewriteQuestion)` | `void` | 影子路由：用户手动选了文档时，后台静默跑一次路由做对比 |
| `recordAutoRoute(conversationId, exchangeId, question, rewriteQuestion, decision)` | `void` | 记录自动路由的结果（用于质量追踪） |
