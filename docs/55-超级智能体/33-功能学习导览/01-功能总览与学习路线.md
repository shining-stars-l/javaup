# 功能总览与学习路线

此篇文档的目的是把 Nexus Agent 项目里所有值得学习的功能点列出来，列出每个功能对应哪些类和方法，这样小伙伴可以根据自己的兴趣直接跳到源码去看。

项目的整体执行流程在后续的文档里会讲解的很详细，这里不再重复了。小伙伴可以理解此章节就像是个"功能菜单"，想学哪个就点哪个。

:::info 说明
下面列出的源码路径都是相对于 `nexus-agent-business-chat` 模块中的。如果没有特别标注模块，默认就是这个位置。
:::

## 功能模块一览

下面按照从"入口"到"深处"的顺序，把项目中的核心功能分成了几个大类。每个功能后面都标注了核心类，方便你直接定位源码。

### 对话入口与生命周期管理

这是整个系统的起点，一个对话请求进来之后，系统怎么接住它、怎么管理它的生命周期。

| 功能 | 核心类 | 关键方法 | 一句话说明 |
|------|--------|----------|-----------|
| SSE流式对话入口 | `BusinessChatController` | `chat()` | 接收前端请求，返回SSE流 |
| 对话主流程编排 | `BusinessChatService` | `openConversationStream()` | 整个对话的总调度，从头到尾 |
| 会话租约（防并发） | `BusinessChatService` | `claimConversationLease()` | 用Redis分布式锁防止同一会话重复请求 |
| JVM任务注册 | `ChatRuntimeRegistry` | `register()` / `remove()` | 单机级别的任务去重 |
| 停止生成 | `BusinessChatService` | `stopConversation()` | 用户点"停止"时的处理逻辑 |
