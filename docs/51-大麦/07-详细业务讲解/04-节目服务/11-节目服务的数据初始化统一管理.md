# 节目服务的数据初始化统一管理

import VipInline from '@site/src/components/VipInline';

在讲解关于项目服务的业务时，会有从redis和elasticsearch中获取数据的流程，但并没有将是什么时候将这些数据放入到redis和elasticsearch中的，在本文中，将详细的介绍节目服务中的数据初始化流程



在节目服务的数据初始化操作时，使用了 **damai-service-initialize** 初始化统一的组件，来实现对初始化操作的统一管理和执行顺序的管理，关于此组件的详细介绍可跳转到相应的文档

[组件讲解-统一服务初始化操作，提升系统启动效率的秘诀](/damai/architecture-components/service-init)



节目服务的初始化操作是使用了组件中的 **AbstractApplicationPostConstructHandler**，也就是 **@PostConstruct** 注解修饰的方法



初始化的操作有四个：



1. **ProgramCategoryInitData** 将节目类型放到redis中
2. **ProgramShowTimeRenewal** 将节目演出时间进行更新
3. **ProgramElasticsearchInitData** 将节目的数据放到elasticsearch中
4. **ProgramBloomFilterInit** 将节目的id集合放入到布隆过滤器中



并且这三者是由执行顺序的
