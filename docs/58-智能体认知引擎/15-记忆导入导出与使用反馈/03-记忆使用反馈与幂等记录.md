# 记忆使用反馈与幂等记录

## 有用、过期和错误三种评价怎样进入后端

外部工具调用 memory_feedback，可以告诉后端“这条记忆有用”“这条记忆已经过期”或“这条记忆不正确”。后端记录 USEFUL、STALE、INCORRECT 之一，保存原因和来源工具，再返回 feedbackId。

这条反馈保存的是调用者的明确评价。当前实现没有根据 STALE 自动改 Atom 生命周期，也没有根据 USEFUL 自动提高召回分数。我先带小伙伴跟完它真正执行的写入流程，再解释它与自动召回 trace 的关系。

| 源码 | 要跟的内容 |
| --- | --- |
| `bootstrap/.../mcp/McpServer.java` | memory_feedback 的写 scope 和参数清单 |
| `bootstrap/.../mcp/McpSharedMemoryToolExecutor.java` | feedback 参数解析、L1 谱系预检查 |
| `memory-evolution/.../api/ExternalMemoryFeedback.java` | Command 字段约束 |
| `memory-evolution/.../internal/JdbcExternalMemoryFeedback.java` | 事务内资格、版本和幂等检查 |
| `memory-evolution/.../internal/ExternalMemoryIdempotency.java` | 指纹计算 |
