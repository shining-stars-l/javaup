# 连接复核与可信召回追踪

## 这一步解决“请求是谁发的、要写到哪里”

HTTP Controller 只确认 JSON 长得对。请求进入 `AutomaticCaptureAdapter.capture()` 后，后端才开始处理权限和项目范围。

这一步按真实调用顺序做三次复核：

1. 当前 principal 必须是 API Token，且有 `external-turns:submit`。
2. 服务端重新读取个人连接 profile、当前项目资格和默认记忆库，再比较请求里的项目绑定回显。
3. 如果请求带了 `recallTraceIds`，逐个查回服务端记录的召回 trace，确认它们确实属于这次连接和会话。

三步都通过后，Adapter 才构造 `ExternalTurnCapture.Command`。之后的数据库写入也在同一个事务里完成。
