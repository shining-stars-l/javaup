# 个人连接创建与项目绑定

## 先把“个人连接”看成一条完整后端链

这里讲的个人连接，不是前端页面上的一条配置记录。后端实际会同时保存三组事实：

- `identity-access` 保存 API Token 的摘要、状态、有效期和 scope；
- `bootstrap.external_connection_profile` 保存这枚 Token 绑定的项目、默认记忆库、用途和绑定修订号；
- 外部凭据保险库保存一份可恢复的加密 secret，详情接口需要重新展示安装信息时才会读取。

浏览器创建连接时，服务端不会接受客户端随便传一个 `projectId` 就直接写入。请求必须先经过浏览器 Authentication Session，再由项目治理模块确认项目仍是 `ACTIVE`，最后才把 Token 和 profile 放进同一个数据库事务。

```text
POST /api/v1/{mcp|automatic-memory|automatic-capture}/configurations
  -> ExternalConnectionController.create
     -> 读取浏览器 principal 和 X-Project-Id 请求头
     -> 根据 URL 选择 ConnectionType
     -> 固定该用途允许的 ApiTokenScope
     -> TransactionalExternalConnectionConfiguration.create
        -> ApiTokenAuthentication.createToken
        -> ExternalConnectionProfiles.bind
           -> 检查 Token 所属用户
           -> 查询 ACTIVE 项目和默认记忆库
           -> 写 external_connection_profile
        -> ExternalCredentialVault.save
     -> 创建响应返回 tokenId.tokenSecret；详情接口按当前凭据复核后可重新读取
```
