# 自动召回与自动会话采集鉴权

## 两条入口各用各的连接，复用鉴权组件

自动召回发生在外部客户端处理问题之前，只读地请求一段当前项目记忆；自动会话采集发生在一轮用户与助手对话完成以后，把完整轮次提交到项目，供后续 L0/L1 处理。

两条入口都使用个人连接，但 scope 和数据边界不同：

| 入口 | HTTP 地址 | 固定 scope | 主要结果 |
| --- | --- | --- | --- |
| 自动召回 | `/api/v1/memory-adapter/recall` | `resources:read` | `OK`、`NONE` 或 `DEGRADED` |
| 自动采集 | `/api/v1/memory-capture/turns` | `external-turns:submit` | 202 + 采集收据 |

自动召回会核对客户端回显的 `projectId` 和 `bindingRevision`，自动采集还会核对 `connectionId`。这些字段都要与服务端解析出的范围比较，不能由客户端随意指定。两条入口使用不同用途的连接，复用 Token 认证、用途过滤和连接范围解析组件。
