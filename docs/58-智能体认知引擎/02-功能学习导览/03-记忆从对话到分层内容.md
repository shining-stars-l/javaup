# 记忆从对话到分层内容

这篇只讲记忆生产线。小伙伴可以拿一轮已经结束的对话来理解：用户问了一个问题，助手给出回答，系统怎样判断它有没有长期价值，最后怎样整理成几层内容。

## 先分清五种内容

| 层次 | 保存什么 | 适合解决什么问题 |
| --- | --- | --- |
| 外部会话 | 客户端带来的会话、轮次和两条原始消息 | 这段话当时到底发生了什么 |
| L0 | 对原始消息的可追踪保存 | 给后续处理提供稳定底稿，保留审计和来源 |
| L1 | 可以单独使用的一条经验或规则 | 以后遇到相似任务时，直接拿一条具体做法参考 |
| L2 | 围绕一个场景整理出的多条经验 | 处理一类事情时，需要遵守哪些组合规则 |
| L3 | 从多个场景归纳出的较稳定原则 | 不同任务都适用的长期约束和偏好 |

越往后，内容越像总结，越需要保留“它从哪里来”。没有来源，后面无法判断一条核心规则是不是还可信，也没法在原始事实变化后重新处理。
