# 团队成员到项目使用资格

## 一次项目记忆请求会经过哪些层

用户登录成功，只代表身份成立。要访问 Agent-Up-Memory 的项目，还要沿着团队成员关系走一遍：用户是否是活跃成员，团队是否还在可用生命周期，项目是否允许团队成员使用，默认记忆库是否就绪，关联是否仍然有效。

先从 `/api/v1/workspace` 和 `/api/v1/workspace/projects` 的 HTTP 入口开始，再进入 `workspace-governance` 的 JDBC 实现。

```text
HTTP 请求
  -> IdentityAuthenticationFilter / McpAuthenticationFilter
     -> AuthenticatedPrincipal
  -> WorkspaceController / ProjectController
     -> WorkspaceQueryContext 或 WorkspaceCommandContext
        -> principal + correlationId + deadline
  -> TeamGovernance / ProjectGovernance / WorkspaceEligibility
  -> JDBC 读取 team、team_membership、project、memory_asset、memory_assignment
  -> revision 校验 + 当前状态判断
  -> EligibilitySnapshot(PERMITTED / DENIED)
```
