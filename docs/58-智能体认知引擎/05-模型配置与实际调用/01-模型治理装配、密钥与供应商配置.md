# 模型治理装配、密钥与供应商配置

## 先把“模型配置”拆成三层

我看这个项目的模型配置时，会先把它拆成三层：

1. **Provider Secret**：供应商密钥。它只负责保存凭据和版本，不负责描述模型。
2. **Provider Configuration**：供应商连接。它记录服务地址、聊天和向量接口路径、使用哪条密钥，以及当前生命周期。
3. **Model Profile**：某个远端模型的档案。它再记录远端模型标识、用途、上下文窗口、输出上限和能力声明。

这三层后面还会通过 `ModelAssignment` 绑定到 `L1_EXTRACT`、`L1_DEDUP`、`L2_EVOLVE`、`L3_SYNTHESIZE` 或 `MEMORY_EMBEDDING`。本篇先讲前两层和 Spring 装配，模型档案、能力探测和用途绑定放到下一篇。

:::info 本篇范围
这里只讲 Java 后端、数据库和供应商 HTTP 配置。管理页面怎样展示表单不在这几篇里展开。
:::
