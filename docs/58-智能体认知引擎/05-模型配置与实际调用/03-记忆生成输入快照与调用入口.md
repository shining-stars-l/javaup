# 记忆生成输入快照与调用入口

## 业务模块不会直接拼供应商 JSON

`memory-evolution` 负责决定这一次要做 L1 提取、L1 去重、L2 场景整理还是 L3 核心归纳。它把业务输入交给 `SystemMemoryGeneration`，由 `model-runtime` 负责固定模型、读取 Prompt 和生成策略、渲染规范请求，最后调用 `LanguageModelRuntime`。

这条边界的设定是很重要的：业务模块知道记忆内容和任务角色，模型运行时知道供应商协议和版本快照。后面更换 OpenAI 兼容服务时，L1/L2/L3 的业务代码不用跟着改 HTTP JSON。
