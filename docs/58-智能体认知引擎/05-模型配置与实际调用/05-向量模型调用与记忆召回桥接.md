# 向量模型调用与记忆召回桥接

## 向量模型和聊天模型是两条后端路径

聊天模型返回文本或结构化 JSON，向量模型返回一组数字。项目没有把两者混在 `LanguageModelRuntime` 里，而是提供独立接口：

```java
public interface EmbeddingRuntime {
    EmbeddingResult embed(EmbeddingRuntimeCommand command);
}
```

向量模型通过 `ModelAssignmentRole.MEMORY_EMBEDDING` 绑定。它还要配合 `EmbeddingSpacePolicy`，确定两个空间：

- `DOCUMENT`：给记忆内容建立索引时使用。
- `QUERY`：用户召回记忆时，把查询文本转换成向量时使用。

两者必须属于同一个 profile、revision 和 dimension。否则索引里的向量和查询向量没有可比性。
