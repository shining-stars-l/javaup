# 历史回填怎样预览创建并执行

## 从请求入口看，回填要提交什么

历史回填是用户主动请求的一次 L2 或 L3 重新计算。它读取已有高层谱系中记录的历史直接来源版本，生成一个待处理 Job。请求体给目标层级、规则版本和预期授权 revision；具体来源版本由后端查库决定。预览只给出计划，不会运行模型。

`HighLevelMemoryEvolutionController` 在同一个记忆库路径下提供预览、创建、暂停和恢复。先看前两个入口：

```java
    /** 把 HTTP 参数转成回填预览命令；来源版本由服务端谱系查询决定。 */
    @PostMapping("/backfills/preview")
    ResponseEntity<Map<String, Object>> previewBackfill(
            @PathVariable("memoryAssetId") UUID memoryAssetId,
            @RequestBody BackfillRequest body,
            @RequestHeader("Idempotency-Key") UUID idempotencyKey,
            @RequestHeader(value = "X-Correlation-Id", required = false) UUID correlationId,
            HttpServletRequest request) {
        // 操作者来自前置认证，幂等键来自请求头，客户端只提交层级、规则和授权版本。
        WorkspaceCommandContext context = commandContext(request, idempotencyKey, correlationId);
        MemoryBackfill.Preview preview = backfills.preview(new MemoryBackfill.PreviewRequest(
                context, new MemoryAssetId(memoryAssetId), body.targetLevel(),
                new EvolutionRuleVersion(body.ruleVersion()),
                new AuthorizationRevision(body.expectedAuthorizationRevision())));
        return ResponseEntity.ok().cacheControl(CacheControl.noStore())
                .body(HighLevelMemoryEvolutionHttpMapper.preview(preview));
    }

    /** 创建前重新预览一次，随后将同一份冻结输入交给回填命令。 */
    @PostMapping("/backfills")
    ResponseEntity<Map<String, Object>> requestBackfill(
            @PathVariable("memoryAssetId") UUID memoryAssetId,
            @RequestBody BackfillRequest body,
            @RequestHeader("Idempotency-Key") UUID idempotencyKey,
            @RequestHeader(value = "X-Correlation-Id", required = false) UUID correlationId,
            HttpServletRequest request) {
        WorkspaceCommandContext context = commandContext(request, idempotencyKey, correlationId);
        // 请求体中的回填范围不直接进入 Job；每次创建都由后端计算预览。
        MemoryBackfill.Preview preview = backfills.preview(new MemoryBackfill.PreviewRequest(
                context, new MemoryAssetId(memoryAssetId), body.targetLevel(),
                new EvolutionRuleVersion(body.ruleVersion()),
                new AuthorizationRevision(body.expectedAuthorizationRevision())));
        MemoryBackfill.Run run = backfills.request(new MemoryBackfill.Request(context, preview));
        return ResponseEntity.ok().cacheControl(CacheControl.noStore())
                .body(HighLevelMemoryEvolutionHttpMapper.run(run));
    }
```

入口从认证后的请求取操作者，从 `Idempotency-Key` 请求头取幂等键，组装 `WorkspaceCommandContext`。预览直接返回后端算出的输入；创建接口会**重新预览**，再把这份预览交给 `request()`。因此，用户先前看到的预览和后来创建时的来源可能不同；创建时真正冻结的是后端当次重新计算的输入。响应设置 `no-store`，避免把治理结果留在浏览器缓存里。
