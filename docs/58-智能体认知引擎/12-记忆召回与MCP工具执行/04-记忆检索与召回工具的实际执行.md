# 记忆检索与召回工具的实际执行

## 从 `tools/call` 继续往里看

上一篇在 `McpServer` 调用 `McpToolExecutor.execute()` 处停下。生产实现是 `McpSharedMemoryToolExecutor`。这里有两个名字相近、实际行为不同的只读工具：`memory_search` 是显式检索当前投影快照，做字符串匹配并返回有界列表；`memory_recall` 调用前两篇的自动召回管道，返回稳定和动态上下文。不要把 `memory_search` 写成“直接调用 BM25/HNSW”，生产代码并不是这样走的。
