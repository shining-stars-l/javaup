# 召回入口、权限与候选检索

## 先看这次召回从哪里进来

后端对外提供的是 `MemoryRecall.recall(Recall)`。自动召回适配器和 MCP 的 `memory_recall` 都会调用它。调用方带来已认证的 `principal`、项目 ID、连接绑定的捕获目标记忆库、当前用户消息、最多两条旧用户消息、追踪 ID 和截止时间。MCP 工具不会自己写一套召回算法；它只把协议参数转成这份命令。

本篇走到候选检索完成为止。接下来的融合、预算和最终交付在下一篇紧接着讲。上一个目录中已经讲了索引如何构建，这里从一次真实查询开始。
