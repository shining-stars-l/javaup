# L1记忆提案读取与审核

## 提案里保存了哪两份正文

L1 自动处理发现当前版本由人工维护时，不会直接覆盖它。发布链会保存一条 `memory_proposal`，其中最关键的是：

- `manual_target_version_id`：生成候选时看到的人工当前版本；
- `automatic_candidate_version_id`：自动流程已经写好的候选版本；
- `input_digest` 和 `rule_version`：这次自动判断使用的输入与规则身份；
- `status` 和 `revision`：审核状态和并发版本；
- 来源 Job、Attempt、fencing token、decision ID：后续证明这条候选来自一次成功处理。

因此，点击接受时不需要临时再调用模型。候选版本早已作为不可变事实落库，审核动作只负责复核条件并切换 Atom 的当前版本指针。
