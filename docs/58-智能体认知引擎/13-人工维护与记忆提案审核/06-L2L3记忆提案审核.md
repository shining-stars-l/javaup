# L2L3记忆提案审核

## 高层提案列表会保留已结束记录

高层提案入口是：

```text
GET  /api/v1/memory-assets/{memoryAssetId}/high-level-proposals
GET  /api/v1/memory-assets/{memoryAssetId}/high-level-proposals/{proposalId}
POST /api/v1/memory-assets/{memoryAssetId}/high-level-proposals/{proposalId}/accept
POST /api/v1/memory-assets/{memoryAssetId}/high-level-proposals/{proposalId}/reject
```

列表读模型与 L1 有一个实际差异。L1 列表 SQL 带 `status = 'PENDING_REVIEW'`，高层列表没有状态过滤：

```java
/** 分页返回当前记忆库的全部高层提案状态，包含已结束的审核记录。 */
@Override
public Page<HighLevelMemoryProposalSnapshot> listProposals(ListProposals query) {
    Objects.requireNonNull(query, "query");
    // 高层列表保留所有状态，调用方可以同时查看待审提案和历史审核结果。
    requireReadable(query.context(), query.memoryAssetId());
    String scope = query.memoryAssetId().value().toString();
    Anchor anchor = query.page().cursor().map(v -> decode(v, "PROPOSAL", scope)).orElse(null);
    try {
        JdbcClient.StatementSpec statement = anchor == null
                ? jdbc.sql("select proposal_id from memory_evolution.high_level_memory_proposal "
                                + "where memory_asset_id = ? order by created_at, proposal_id limit ?")
                        .params(query.memoryAssetId().value(), query.page().limit() + 1)
                : jdbc.sql("select proposal_id from memory_evolution.high_level_memory_proposal "
                                + "where memory_asset_id = ? "
                                + "and (created_at > ? or (created_at = ? and proposal_id > ?)) "
                                + "order by created_at, proposal_id limit ?")
                        .params(query.memoryAssetId().value(), Timestamp.from(anchor.timestamp()),
                                Timestamp.from(anchor.timestamp()), anchor.id(), query.page().limit() + 1);
        List<HighLevelMemoryProposalSnapshot> fetched = statement.query(UUID.class).list().stream()
                .map(MemoryProposalId::new)
                .map(facts::findProposal)
                .flatMap(Optional::stream)
                .toList();
        return page(fetched, query.page().limit(), "PROPOSAL", scope,
                HighLevelMemoryProposalSnapshot::createdAt, v -> v.proposalId().value());
    } catch (DataAccessException exception) {
        throw failure(MemoryEvolutionReadModelException.Code.PERSISTENCE_UNAVAILABLE);
    }
}
```

因此高层列表可用于查看待审和历史审核结果。前端若只想展示待办，需要根据返回的 status 自己筛选或提供对应视图，不能假设服务端只返回 `PENDING_REVIEW`。

游标带类型和记忆库 scope。把另一个资源或另一类列表的 cursor 塞进来会被解码校验拒绝，避免分页跨范围漂移。
