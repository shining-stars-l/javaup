# L1创建编辑与生命周期维护

## 创建一条人工原子记忆

创建命令带来六类输入：操作者上下文、记忆库 ID、授权 revision、Atom 类型、正文和可选来源。它不需要 Atom revision，因为后端会生成新 Atom。

`JdbcL1ManualGovernance.create()` 的执行顺序如下：

```java
/** 创建 Atom、首个人工版本和谱系，并把幂等回执与投影通知写进同一个事务。 */
private Result create(Create command, String operation, String fingerprint) {
    Instant now = clock.instant();
    // Atom、首个版本和谱系各自有稳定身份，使用有时间顺序的 UUID 方便数据库索引写入。
    L1AtomId atomId = new L1AtomId(UuidCreator.getTimeOrderedEpoch());
    MemoryVersionId versionId = new MemoryVersionId(UuidCreator.getTimeOrderedEpoch());
    MemoryLineageId lineageId = new MemoryLineageId(UuidCreator.getTimeOrderedEpoch());
    jdbc.sql("insert into memory_evolution.l1_atom "
                    + "(atom_id, memory_asset_id, atom_type, current_version_id, lifecycle, revision, "
                    + "created_at, changed_at) values (?, ?, ?, ?, 'ACTIVE', 1, ?, ?)")
            .params(atomId.value(), command.memoryAssetId().value(), command.type().name(), versionId.value(),
                    Timestamp.from(now), Timestamp.from(now))
            .update();
    // 正文放进只追加版本表。Atom 只保存当前版本指针和生命周期。
    persistVersion(
            versionId, atomId, command.memoryAssetId(), 1, command.content(),
            MemoryVersionProvenance.MANUAL, now);
    persistManualLineage(
            lineageId, command.memoryAssetId(), versionId, L1EvolutionDecision.STORE,
            command.context().principal().userId(), command.sources(), now);
    L1AtomSnapshot atom = new L1AtomSnapshot(
            atomId, command.memoryAssetId(), command.type(), versionId,
            L1AtomLifecycle.ACTIVE, 1, now, now);
    MemoryVersionSnapshot version = new MemoryVersionSnapshot(
            versionId, atomId, command.memoryAssetId(), 1, command.content(),
            MemoryVersionProvenance.MANUAL, now);
    MemoryLineageSnapshot lineage = new MemoryLineageSnapshot(
            lineageId, command.memoryAssetId(), versionId, L1EvolutionDecision.STORE,
            command.sources(), new MemoryLineageOrigin.Manual(command.context().principal().userId()), now);
    // 先保存可重放回执，再写投影变更；二者仍在同一个数据库事务内。
    insertReceipt(command, operation, fingerprint, atom, Optional.of(version), Optional.of(lineage),
            Optional.empty(), Optional.empty());
    append(atom, MemoryProjectionSource.Operation.UPSERT, command.context().correlationId(), now);
    jdbc.sql("set constraints all immediate").update();
    return contentResult(atom, version, lineage, List.of());
}
```
