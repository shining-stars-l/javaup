# L2L3人工维护与下游协调

## 高层记忆共用一组维护入口

L2 场景记忆和 L3 核心记忆共用 `HighLevelManualController`。创建路径是：

```text
POST /api/v1/memory-assets/{memoryAssetId}/{level:l2|l3}
```

修改路径是：

```text
POST /api/v1/memory-assets/{memoryAssetId}/{level:l2|l3}/{targetId}/{action}
```

`action` 只允许 `edit`、`invalidate`、`reactivate`、`delete`。L1 的回滚和合并没有直接复用到 L2/L3。

```java
/** 把 HTTP 输入转成一份带操作者、幂等键、追踪号和 30 秒期限的写命令。 */
private HighLevelManualGovernance.Result execute(
        HttpServletRequest request,
        UUID key,
        UUID asset,
        String level,
        UUID target,
        String action,
        Body body) {
    WorkspaceCommandContext context = new WorkspaceCommandContext(
            // principal 来自前置认证过滤器，不能从请求体接受操作者身份。
            IdentityHttpSupport.principal(request),
            key,
            UUID.randomUUID(),
            Instant.now().plusSeconds(30));
    return manual.execute(new HighLevelManualGovernance.Command(
            context,
            new MemoryAssetId(asset),
            HighLevelMemoryLevel.valueOf(level.toUpperCase(Locale.ROOT)),
            target,
            HighLevelManualGovernance.Action.valueOf(action),
            body.content(),
            body.reason(),
            // expectedRevision 用来阻止旧页面覆盖别人刚提交的修改。
            body.expectedRevision(),
            // expectedAuthorizationRevision 用来阻止权限变化前打开的页面继续写入。
            new AuthorizationRevision(body.expectedAuthorizationRevision())));
}
```

当前高层接口没有接收来源列表。创建和编辑会写一条人工谱系，origin 记录操作者，sources 是空列表。L1 可以提交来源，L2/L3 目前没有这个参数。
