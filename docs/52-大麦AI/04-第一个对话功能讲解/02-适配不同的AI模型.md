# 适配不同的AI模型

import VipInline from '@site/src/components/VipInline';

## 项目里是怎么做的
这个项目在同一套 Spring AI 架构里同时接入了多种模型能力：

- 对话模型：`deepseek-chat`（主对话与运维分析）
- RAG 问答模型：`qwen-max-latest`（规则问答）
- 向量模型：`text-embedding-v3`（向量化检索）
- 本地模型：`ollama`（可作为本地调试备选）

关键配置在 `damai-core-service/src/main/resources/application.yaml`：

- `spring.ai.deepseek.*`
- `spring.ai.openai.*`
- `spring.ai.ollama.*`
