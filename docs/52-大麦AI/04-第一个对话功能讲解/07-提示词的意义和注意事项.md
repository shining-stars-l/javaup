# 提示词的意义和注意事项

import VipInline from '@site/src/components/VipInline';

## 项目中的提示词分层
### 1) 系统提示词（System Prompt）
定义角色、边界和流程，是最高优先级约束。

- 客服助手：`DaMaiConstant.DA_MAI_SYSTEM_PROMPT`
- 运维助手：`DaMaiConstant.DA_MAI_ANALYSIS_PROMPT`
- RAG助手：`DaMaiConstant.MARK_DOWN_SYSTEM_PROMPT`

### 2) 任务提示词（User Prompt / 增强 Prompt）
由用户输入或后端拼接（例如 RAG v2 的上下文增强 Prompt）。
