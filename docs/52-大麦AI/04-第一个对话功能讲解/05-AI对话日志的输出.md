# AI对话日志的输出

import VipInline from '@site/src/components/VipInline';

## 项目里的两类“日志”
### 1) 运行日志（Log4j2）
- 配置：`damai-core-service/src/main/resources/log4j2.xml`
- 输出目录：`logs/damai-ai/`
- 内容：接口调用、业务日志、Advisor 日志。

### 2) 对话追踪日志（可观测性）
- 实现：`AiObservabilityAdvisor + AiObservabilityService`
- 落库表：`d_ai_trace`
- 字段：`traceId`、`conversationId`、`modelName`、token、latency、cost、输入输出截断内容。

## 调用时机
- `before`：生成 `traceId`，记录开始时间与用户输入。
- `after`：读取模型 usage，计算费用并异步落库。

## 实践建议
- 线上建议把输入/输出字段做脱敏和长度限制（项目已做截断）。
- 为 `traceId` 建立统一链路关联规范，可与网关日志串联。
- 区分“业务日志”和“观测日志”，避免后续排障维度混淆。
