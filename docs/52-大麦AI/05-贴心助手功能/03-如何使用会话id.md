# 如何使用会话id


import VipInline from '@site/src/components/VipInline';

## 前端侧
在 `vue/src/views/*.vue` 中，新会话通常使用：

```js
const newChatId = Date.now().toString()
```

发送消息时将 `chatId` 作为请求参数传给后端，例如：
- `/program/chat?prompt=...&chatId=...`
- `/program/rag?prompt=...&chatId=...`
- `/program/chat/mcp?prompt=...&chatId=...`

## 后端侧
后端在 `ProgramController` 中将 `chatId` 写入 Advisor 上下文：

```java
.param(ChatMemory.CONVERSATION_ID, chatId)
```

随后由 `MessageChatMemoryAdvisor`、`ChatTypeHistoryAdvisor`、`AiObservabilityAdvisor` 等统一消费。
