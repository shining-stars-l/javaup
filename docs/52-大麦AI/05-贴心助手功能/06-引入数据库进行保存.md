# 引入数据库进行保存

import VipInline from '@site/src/components/VipInline';

## 当前落库内容
项目将对话相关数据保存到 MySQL，核心表在 `sql/damai_ai.sql`：

- `d_chat_type_history`：会话类型、chatId、标题
- `d_ai_trace`：AI 调用追踪（token、耗时、费用、输入输出截断）

### 配置入口
`application.yaml`：
- `spring.datasource.*` 指向 `damai_ai`
- `spring.ai.chat.memory.repository.jdbc.initialize-schema: always` 启用 chat memory JDBC schema 初始化

### 业务意义
- 会话列表可持久化，不丢历史。
- 可观测指标可做趋势分析和成本评估。
- 支撑“按会话/按类型”的管理接口。
