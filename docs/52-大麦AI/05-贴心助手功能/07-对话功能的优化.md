# 对话功能的优化

import VipInline from '@site/src/components/VipInline';

## 现有优化总览
项目的对话能力不是单点优化，而是全链路优化：

- 输入阶段：系统提示词约束业务流程与安全边界
- 上下文阶段：`ChatMemory` 维持多轮记忆
- 执行阶段：工具调用（函数调用 / MCP）增强外部能力
- 输出阶段：流式返回提升交互体验
- 运营阶段：可观测性记录 token、延迟、成本

### 关键实现
- 控制器：`ProgramController`（客服/RAG/运维三入口）
- 对话增强：`ChatTypeHistoryAdvisor`、`ChatTypeTitleAdvisor`
- 可观测性：`AiObservabilityAdvisor`、`AiEnhanceController`
- 前端体验：`vue/src/views/*.vue` 中的流式读取与会话历史侧边栏
