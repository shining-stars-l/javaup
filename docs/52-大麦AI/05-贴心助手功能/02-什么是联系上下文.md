# 什么是联系上下文

import VipInline from '@site/src/components/VipInline';

## 概念
“连续上下文”指模型在多轮对话中记住同一会话的历史消息，并基于历史继续回答。

如果没有上下文，模型每轮都像“第一次见你”。

在 `ProgramController` 的各聊天接口中，都会传：

```java
.advisors(a -> a.param(ChatMemory.CONVERSATION_ID, chatId))
```

### 业务收益
- 用户不用每轮重复提供城市、节目、偏好等信息。
- 标题生成、历史回放都可基于完整会话。
